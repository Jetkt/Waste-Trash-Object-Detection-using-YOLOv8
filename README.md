# Waste-Trash-Object-Detection-using-YOLOv8
Sistem deteksi objek berbasis YOLOv8 untuk mengenali jenis sampah (plastik, kertas) secara real-time. Dilatih dengan dataset Roboflow, proyek ini membantu otomatisasi pengelolaan sampah melalui klasifikasi akurat untuk mendukung lingkungan yang lebih bersih.
